Todo valor tem a mesma chance de sair — isso é a Uniforme Discreta

Imagine um dado honesto: cada face tem exatamente 1/6 de chance de cair para cima. Nenhuma face é favorecida. Essa é a ideia da Distribuição Uniforme Discreta: um número finito de valores possíveis, a até b, onde cada um deles é igualmente provável. É a distribuição mais "justa" e mais simples que existe — e está escondida em dados, roletas, sorteios, geradores de números aleatórios e muito mais. Vamos construir essa ideia do zero, com muitos desenhos, dados virtuais e simulações.

Fundamentos
🎲 O que é a Distribuição Uniforme Discreta?

Pense num dado com n faces, numeradas de 1 até n. Toda vez que você joga esse dado, qualquer face tem exatamente a mesma chance de cair para cima: 1/n. O valor que sai é a variável X, e escrevemos X ~ Uniforme Discreta{1,...,n} (ou, de forma mais geral, U{a,...,b}). Ajuste o número de faces abaixo e jogue o dado para ver X nascer na sua frente.

A ideia central

A Uniforme Discreta é sobre total igualdade de chances entre um número finito de valores. Não existe "favorito": cada valor pesa exatamente o mesmo 1/n — é o oposto de distribuições como a Binomial ou a Poisson, que quase sempre têm um valor mais provável que os outros.

O Teste Antes de Usar a Fórmula
✅ As 4 condições: use o truque DADO

Nem toda variável com valores discretos é Uniforme! Para garantir que você pode usar a fórmula, confira as 4 condições — e o jeito mais fácil de lembrar é a própria palavra DADO (nem por acaso, o exemplo clássico é literalmente um dado).

D
Discreto
Os valores são contáveis e separados (ex.: números inteiros) — não formam um intervalo contínuo.
A
Amplitude fixa
Os valores vão de um mínimo a até um máximo b, conhecidos antes de sortear.
D
Distribuição igual
Cada valor possível tem exatamente a mesma probabilidade 1/n de sair.
O
Only uma vez (um só sorteio)
Estamos descrevendo um único sorteio — não uma sequência de tentativas como na Binomial.

💡 Repare que "igualmente provável" é a peça-chave: se um dado é viciado (uma face sai mais que as outras), não é mais uma Uniforme Discreta — vira uma distribuição discreta qualquer, sem essa simetria perfeita.

Os Dois Números Que Definem Tudo
🎚️ Os parâmetros a e b (e o n que nasce deles)

A Uniforme Discreta precisa de apenas dois números para ficar completamente definida: a (o menor valor possível) e b (o maior valor possível). A partir deles, a quantidade de valores possíveis é n = b − a + 1 — repare no +1: como os dois extremos entram na contagem, é fácil esquecer essa soma. Arraste os controles e veja o "retrato" da distribuição (sempre um retângulo!) mudar de largura.

O Retrato Completo da Uniforme Discreta
📊 Distribuição de Probabilidade (PMF): todo mundo empatado

A fórmula é a mais simples de toda a estatística: P(X=k) = 1/n para qualquer k entre a e b — e 0 para qualquer outro valor fora desse intervalo. Não existe combinatória, não existe expoente: é só "1 dividido pela quantidade de valores possíveis". Arraste os controles e veja todas as barrinhas ficarem sempre com a mesma altura.

A regra de ouro da PMF

Some todas as barrinhas possíveis (de k=a até k=b, ou seja, n barrinhas de altura 1/n) e o resultado é sempre exatamente 1 — n × (1/n) = 1, não importa quais a e b você escolher.

Somando a Probabilidade Aos Poucos
📶 Função Acumulada (CDF): uma escada com degraus idênticos

A função acumulada F(k) = P(X ≤ k) = (k−a+1)/n responde "qual a chance de X ser até esse valor?". Como cada valor pesa a mesma coisa, a CDF da Uniforme Discreta é uma escada perfeitamente regular — cada degrau sobe exatamente 1/n, nem mais nem menos. Isso é bem diferente de outras distribuições, onde os degraus têm alturas desiguais.

A função acumulada nunca diminui e, diferente de quase toda outra distribuição, sobe em degraus iguais — é uma reta em forma de escada. No valor b ela já vale exatamente 1.

O "Centro de Gravidade" da Uniforme Discreta
⚖️ Valor Esperado E(X) = (a+b)/2

Como todos os valores pesam igual, o valor esperado é simplesmente o ponto médio entre o menor e o maior valor: E(X) = (a+b)/2. Pense numa gangorra perfeitamente equilibrada: se cada valor tem o mesmo "peso", o ponto de equilíbrio cai exatamente no meio do intervalo — nem para a esquerda, nem para a direita.

Ajuste a e b e veja a linha tracejada marcar E(X) = (a+b)/2 bem no meio da distribuição
⬇️ a — mínimo1
⬆️ b — máximo10
E(X) = (a+b)/25.5
Cuidado: E(X) não precisa ser um valor possível!

Se a e b tiverem paridades diferentes (um par, outro ímpar), (a+b)/2 dá um número quebrado (ex.: dado de 6 faces → E(X)=3,5), mesmo que X só possa assumir valores inteiros. É uma média de longo prazo, jogando o dado muitas vezes, não uma previsão de uma única jogada.

O Quão Espalhados Estão os Valores
📏 Variância: Var(X) = (n²−1)/12

A variância mede o quão "espalhados" os valores estão ao redor da média. Para a Uniforme Discreta, a fórmula é Var(X) = (n²−1)/12, onde n = b−a+1. Repare que essa fórmula só depende de n (quantos valores existem), não de onde eles começam — deslocar o intervalo inteiro (por exemplo, de {1,...,6} para {101,...,106}) não muda nadinha a variância, só a média.

Por que isso importa?

A variância só "enxerga" a largura do intervalo, não sua posição. Isso faz sentido: espalhar os valores mais para longe da média (aumentar n) aumenta a incerteza; simplesmente mover todo mundo para a direita ou esquerda não muda o quão espalhados eles estão entre si.

A Única Distribuição Que Nunca Muda de Cara
📐 A forma: sempre um retângulo perfeito

Diferente de quase toda outra distribuição (Binomial, Poisson, Hipergeométrica...), a Uniforme Discreta nunca fica assimétrica, nunca tem um "pico" — ela é sempre um retângulo perfeitamente plano, não importa quantos valores existam. É por isso que ela também é chamada de distribuição retangular. Compare abaixo um dado pequeno, médio e grande: a altura das barras muda (porque n muda), mas a forma continua sempre a mesma — chata e reta.

n=3 — ex.: pedra-papel-tesoura
n=12 — ex.: meses do ano
n=37 — ex.: roleta 0–36

Ligando os Pontos com Outras Distribuições
🔗 Conexões: a Uniforme Discreta não está sozinha

A Uniforme Discreta é a distribuição mais simples de todas — e por isso ela aparece "escondida" dentro de outras. Duas conexões valem a pena guardar:

🪙 Caso especial: n=2 vira Bernoulli(0,5)
Se X ~ Uniforme Discreta{0,1}, então P(X=0)=P(X=1)=1/2 — é exatamente uma Bernoulli com p=0,5, como jogar uma moeda honesta. A Bernoulli "justa" é só um caso particular da Uniforme Discreta com apenas dois valores.
📏 Prima da Uniforme Contínua
A versão "contínua" dessa distribuição (usada para sortear um número real qualquer entre a e b, como o ponteiro de uma roleta que gira livremente) tem a mesma cara: retângulo plano, mesma fórmula de esperança (a+b)/2, e uma fórmula de variância parecida — (b−a)²/12, sem o "−1" que aparece na versão discreta. Pense na Uniforme Discreta como uma versão "pixelada" (em degraus) da Uniforme Contínua.

💡 Também dá pra generalizar: a Uniforme Discreta não precisa ser sobre números consecutivos. Sortear igualmente entre {2,4,6,8} ou entre {"cara","coroa"} também é Uniforme Discreta — o essencial é ter uma lista finita e todo mundo com a mesma chance. As fórmulas de E(X) e Var(X) desta aula valem para o caso clássico de valores inteiros consecutivos (a, a+1, ..., b).

✅ Boas práticas: como não se confundir
Antes de aplicar a fórmula da Uniforme Discreta: todos os valores possíveis são realmente igualmente prováveis?
✅ Sim, valores discretos e igualmente prováveis
➡️ É uma Uniforme Discreta{a,...,b}
Ex.: dado honesto, roleta honesta, sorteio de bilhetes numerados.
🚫 Não, alguns valores são mais prováveis
➡️ Procure outro modelo (Binomial, Poisson, Normal...)
Ex.: número de gols num jogo, notas de prova, idades de pessoas.
1️⃣ Não esqueça o "+1" no n
n = b−a+1, não b−a. Um dado de 1 a 6 tem 6 faces, não 5 — os dois extremos contam.
2️⃣ "Aleatório" não é sinônimo de "uniforme"
Um número "aleatório" pode vir de qualquer distribuição. Só é Uniforme Discreta se cada valor tiver exatamente a mesma probabilidade.
3️⃣ Não confunda com a versão contínua
Uniforme Discreta conta valores inteiros separados (fórmulas com n e −1). Uniforme Contínua mede um intervalo real (fórmulas sem o −1).
Erro comum #1: assumir uniformidade sem verificar

Nem todo "sorteio" é justo. Uma roleta viciada, um dado de chumbo, uma "escolha aleatória" de clientes que na prática favorece alguns grupos — nenhum desses é Uniforme Discreta de verdade. Sempre confirme que as probabilidades são realmente iguais.

Erro comum #2: aplicar a fórmula de variância errada

Misturar (n²−1)/12 (discreta) com (b−a)²/12 (contínua) é um erro clássico. Se os valores são inteiros e contáveis, use a versão com n e o −1.
