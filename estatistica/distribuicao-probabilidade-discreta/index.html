Toda vez que o acaso só pode cair em números contáveis, existe uma Distribuição Discreta

Quantos filhos tem uma família? Qual número saiu no dado? Quantos clientes entraram na loja? Todas essas perguntas têm algo em comum: a resposta é sempre um número que dá para contar — 0, 1, 2, 3... nunca "2,3781" ou qualquer valor no meio. Sempre que isso acontece, existe uma Distribuição de Probabilidade Discreta escondida por trás, descrevendo quais valores são mais prováveis e quais são mais raros. Nesta aula vamos construir essa ideia do zero — com dados, urnas e muitos gráficos — até você enxergar a "família" completa de distribuições discretas mais usadas na prática.

Fundamentos
🔤 O que é uma Variável Aleatória?

Uma Variável Aleatória (chamamos de X) é só uma régua numérica que colocamos em cima de um experimento com resultado incerto. Em vez de dizer "saiu a face com o cachorro desenhado", dizemos "saiu o número 4". A variável aleatória é a ponte entre o mundo real (moedas, dados, clientes, ligações) e os números que sabemos somar, multiplicar e colocar em gráfico. Quando essa régua só admite valores contáveis (0, 1, 2, 3...) — nunca frações intermediárias como 1,5 — chamamos essa variável de discreta. Clique nos exemplos abaixo para ver a régua em ação.

A ideia central

Não importa se o experimento é jogar um dado, contar clientes ou testar remédios — toda variável aleatória discreta pode ser descrita do mesmo jeito: uma lista de valores possíveis, cada um com sua própria probabilidade. É essa lista organizada que chamamos de distribuição de probabilidade.

A Primeira Bifurcação
🔍 Discreta ou Contínua? O primeiro diagnóstico

Antes de escolher qualquer fórmula, pergunte: "dá para contar nos dedos (mesmo que precise de infinitos dedos), ou só dá para medir com uma régua/relógio?". Se dá para contar (0, 1, 2, 3...) — mesmo que a lista seja infinita — a variável é discreta. Se o valor pode ser qualquer número dentro de um intervalo (como 1,732859...), a variável é contínua. Essa distinção decide quais ferramentas matemáticas usar depois. Clique em cada exemplo abaixo e treine o olho.

De Onde a Distribuição Realmente Vem
🗺️ Do Espaço Amostral até a Distribuição

Toda distribuição nasce de um espaço amostral — a lista de todos os resultados possíveis. Jogue dois dados e some os pontos: existem 36 combinações possíveis (6 × 6), mas várias delas dão a mesma soma. Por exemplo, a soma 7 pode sair de 6 jeitos diferentes (1+6, 2+5, 3+4, 4+3, 5+2, 6+1), enquanto a soma 2 só sai de 1 jeito (1+1). É por isso que somas no meio (como 7) são muito mais prováveis que somas nas pontas (como 2 ou 12) — e é exatamente esse padrão que forma a distribuição.

O Retrato Completo da Variável
📊 Função de Probabilidade (PMF): P(X=k)

A PMF (Probability Mass Function, ou Função de Probabilidade) é uma tabela — ou um gráfico de barras — que diz, para cada valor possível de X, qual é a chance dele acontecer: P(X=k). Ela obedece a duas regras de ouro, sem exceção: cada barra tem altura maior ou igual a zero (não existe chance negativa!), e a soma de todas as barras é exatamente 1 (100% de chance está distribuída entre os valores possíveis). Use o controle abaixo para "viciar" um dado e veja a PMF mudar de forma — mas nunca deixar de somar 1.

A regra de ouro da PMF

Não importa o quão "viciado" você deixe o dado — Σ P(X=k) sempre dá exatamente 1, porque alguma face vai sair. Isso vale para qualquer distribuição discreta, não só para dados: moedas, contagem de clientes, número de defeitos — todas obedecem a essas duas regras.

Somando a Probabilidade Aos Poucos
📶 Função de Distribuição Acumulada (CDF): F(x) = P(X≤x)

A CDF responde "qual a chance de X ser até esse valor?". Numa variável discreta, ela é sempre uma escadinha: fica parada entre um valor possível e o próximo, e dá um "salto" exatamente na altura da PMF quando passa por cada valor. No dado, ela sobe de degrau em degrau — cada degrau tem a altura de P(X=k). Ajuste o peso do lado 6 e arraste x para ver a escada em ação.

O "Centro de Gravidade" da Distribuição
⚖️ Valor Esperado E(X): a média de longo prazo

O Valor Esperado E(X) = Σ k × P(X=k) é a média de X se repetíssemos o experimento infinitas vezes. Pense numa balança: colocamos um peso em cada valor possível, proporcional à sua probabilidade, e o ponto de equilíbrio é E(X). Num dado honesto, todos os pesos são iguais e a balança equilibra bem no meio, em 3,5. Vicie o dado e veja a balança pender para o lado mais pesado.

O Quão Imprevisível é o Resultado
📏 Variância Var(X): o quanto os valores se espalham

A Variância Var(X) = Σ (k − E(X))² × P(X=k) mede o quanto X costuma se afastar da própria média. Cada barra do gráfico abaixo mostra quanto cada face contribui para essa "distância ao quadrado" total. Por que isso importa?

Quanto mais "achatada e espalhada" a PMF, maior a variância — mais difícil prever o resultado de um lançamento individual. Quanto mais concentrada em poucos valores, menor a variância — mais previsível. Variância é, literalmente, uma nota para "quão surpreendente" costuma ser o resultado.

Antes de Sair Aplicando Fórmula
🧭 Boas práticas: como não se confundir
Antes de montar qualquer distribuição: os valores possíveis de X dão para contar (0,1,2,3...) ou só dá para medir com régua/relógio?
✅ Dá para contar
➡️ É uma Variável Discreta — use PMF, ΣP(X=k)=1
Ex.: número de filhos, resultado de um dado, número de defeitos.
❌ Só dá para medir
➡️ É uma Variável Contínua — precisa de densidade de probabilidade (outra aula)
Ex.: altura, peso, tempo de espera, temperatura.
1️⃣ PMF não é a probabilidade "acumulada"
P(X=k) é a chance de X ser exatamente k. Se quiser "até k" ou "menos que k", use a CDF, não a PMF.
2️⃣ E(X) é uma média, não uma previsão
E(X)=3,5 num dado não significa que vai sair 3,5 — significa que essa é a média de infinitos lançamentos.
3️⃣ Nem toda soma de números é uma PMF válida
Sempre confira: todos os valores ≥ 0 e a soma total é exatamente 1. Sem isso, não é uma distribuição de probabilidade.
Erro comum #1: achar que "discreto" significa "poucos valores"

Não! Uma variável discreta pode ter infinitos valores possíveis (como "número de tentativas até acertar", que pode ser 1, 2, 3... sem limite). O que define "discreto" é ser contável, não ser finito.

Erro comum #2: confundir PMF com CDF

PMF é a altura de uma barra só (P(X=k)). CDF é a soma acumulada de todas as barras até aquele ponto (P(X≤k)). São gráficos visualmente diferentes: barras isoladas versus uma escada.

Dica de ouro

Toda vez que encontrar uma variável nova, escreva a lista de valores possíveis e as probabilidades de cada um. Se a soma bater em 1 e nada for negativo, você já tem uma distribuição de probabilidade válida em mãos — o resto (E(X), Var(X), gráficos) é só aplicar fórmula.
